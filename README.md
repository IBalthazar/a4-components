## Assignment Tracker

https://a4-isaiahbalthazar.onrender.com/



Summary

I built an Assignment Tracker where you can input any assignment you need to complete along with its category and due date. There is also a Priority Level for major assignments that changes based on how close it is to the deadline. Users also have the ability to edit and/or delete any existing data they have submitted. 

Did the technology hinder of improve the development expereirence?

Honestly I'd say using React actually improved the development experience as although It was a bit of a learning curve, I was able to have more structure and organization to my program files. I used different files for various different website components and react allowed me to bring all of these componets together and fit them in like a puzzle piece. Using components made the experience a little more efficient as well. Some changes I did make besides splitting my program into separate components was moving faway from require and using imports as require doesnt work with React.
